# Starter Kit : Minimalist Dashboard (Antigravity)

Ce kit de démarrage est optimisé pour un workflow "Zero-Friction" avec des agents IA (Antigravity). Il contient les règles d'architecture, de design system et de comportement agent nécessaires pour coder en autonomie.

## Workflow Recommandé

### Étape 0 : Préparation (Toi)
1. Copie ce dossier pour ton nouveau projet.
2. Fais un `git init` et un premier commit.
3. Configure ton MCP Supabase/Firebase si nécessaire dans `~/.gemini/antigravity/mcp_config.json`.

### Étape 1 : Définition (Toi + IA)
Ouvre Antigravity et lance l'interview de définition :
> `/grill-me` (ou `/impeccable init`)

Réponds aux questions de l'agent. Il remplira le fichier `PRODUCT.md` de manière autonome.

### Étape 2 : Architecture (Toi + IA)
Demande à l'agent de créer le plan technique :
> `/impeccable shape`

L'agent générera un `implementation_plan.md`. Lis-le et donne ton approbation finale.

### Étape 3 : Exécution Autonome (IA seule)
Lance la machine avec une commande minimaliste :
> `/goal` et `/teamwork-preview`
> *Exécute l'intégralité du plan d'implémentation en appliquant strictement le **Protocole d'Exécution Autonome** défini dans AGENTS.md.*

### Étape 4 : Finitions (IA)
Pour valider l'UI par rapport au `DESIGN.md` :
> `/impeccable polish`
> *Lance un browser agent sur Desktop et Mobile, audite l'UI, corrige les dépassements, et documente avec des captures d'écran dans le `walkthrough.md`.*
